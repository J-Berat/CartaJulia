# MANTA Documentation

The README is intentionally short: installation, quickstart, and compact usage
examples. Detailed documentation is split across these pages:

- [User guide](user-guide.md): viewer capabilities, in-memory data, batch export, lazy loading, masks, power spectra, dark mode, and keyboard shortcuts.
- [Reference](reference.md): complete `manta` keyword options, plugin API, and HDF5 conventions.
- [Development](development.md): test commands, Docker notes, troubleshooting, and repository layout.

Docker-specific usage is documented separately in [../DOCKER.md](../DOCKER.md).
